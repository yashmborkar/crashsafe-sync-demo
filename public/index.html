    What the library guarantees

    Atomic page commits

    Customer UPSERTs and the checkpoint commit in one PostgreSQL transaction. A database error rolls back that page.

    One active worker per sync key

    Leases coordinate workers. Fencing blocks an old worker from committing after another worker takes over.

    At-least-once processing

    Pages can be replayed. Stable IDs and UPSERTs prevent duplicate rows here. Exactly-once callbacks and external effects are outside the guarantee.
